Data issues found

  • Island Princess: the ship page says 987 guest cabins, but the deck plan lists 1,107. The page fact looks out of date.
  • "Makato Ocean" is misspelled in the deck plan (the restaurant is Makoto Ocean) on Sapphire, Star, Sun.
  • Deck plan pages for ships with two layouts return "Service temporarily unavailable" if a request has no language setting. Normal browsers always send one, so visitors aren't affected, but simple monitoring tools and some bots get an error page.
