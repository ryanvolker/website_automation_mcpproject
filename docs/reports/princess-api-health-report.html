What needs attention

Every check that failed or warned, most serious first.

Warning Content API · Global header (navigation)

The navigation data includes a demo promotion attached to the Packages menu item: title “Lorem Ipsum Dolor”, Latin placeholder text, and an image from a cfm-assets-demo folder. It was hidden in every menu we opened, but it is sent to every visitor on every page and would appear if that promotion slot were switched on. Fix: remove the promotion from the Packages menu item in the content system.

  • no placeholders or "undefined" in content: Lorem Ipsum

Warning Content API · Sale names

The sale-name lookup file still lists sales that ended on November 2 (Spooky Savings, Fly for Less, Free Onboard Spend). The site looks up names here, so this is low risk unless an old fare still carries one of these codes. Fix: confirm the file is cleaned up automatically after a sale ends.

  • no expired sales still listed: 7 expired: Spooky Savings (BOO-PO, ended 2026-11-02); Fly for less with Princess (FL1-PO, ended 2026-11-02); Fly for less with Princess (FL2-PO, ended 2026-11-02); Free Onboard Spend (OB1-PO, ended 2026-11-02); Free Onboard Spend (OB2-PO, ended 2026-11-02); Free Onboard Spend (OB3-PO, ended 2026-11-02); Free Onboard Spend (OB4-PO, ended 2026-11-02)

Warning Page journey · Alaska destination

The Alaska region page was usable after 2.1 seconds but took 8.6 seconds to finish loading, the slowest of the pages checked. It loads two full-screen hero videos and 400+ requests. Fix: lazy-load the hero videos or use lighter poster images on first view.

  • page loads in under 8s: loaded in 8.6s, usable at 2.1s

Warning Page journey · JavaScript errors (all pages)

Every page throws n.includes is not a function inside Google Tag Manager's server-side service worker (/gtmfp02/). Visitors don't see it, but tracking that relies on that worker may be losing data. It was seen in automated Chrome and should be confirmed in a normal browser. Fix: ask the analytics team to check the GTM server-side container setup.

  • JavaScript error on 9 of 9 pages: n.includes is not a function (in www.princess.com/gtmfp02/_/service_worker/6al0/sw_iframe.html)

How the site is wired

What a visitor's browser talks to when it loads princess.com.

Pages & content

www.princess.com serves the pages. Navigation, port data and packages come from its content API (/graphql/execute.json/…), and sale lists from static JSON files.

Cruise data API

gw.api.princess.com supplies cruises, live prices, deals, ships, ports and visitor locale. It only answers requests from the site's own pages.

Commerce & search

Shore-excursion carts run on Salesforce Commerce Cloud. Coveo powers search and the blog listing, and Swiftype the search box.

Images

assets.princess.com (Adobe Scene7) resizes and serves photos.

Marketing & measurement

Adobe Launch loads 14 advertising services, plus analytics, session recording, A/B testing and monitoring tools.

How this was checked

  • Discovery: 12 pages were loaded in Chromium and every request was recorded (3,838 in total).
  • Direct checks: the open content APIs, sale lists, robots.txt and sitemap were called with plain GET requests and checked for status, speed (warning over 1 s, failure over 5 s) and expected data.
  • Page journeys: the cruise data API refuses calls from outside the site (401/403), so it was checked the way a visitor uses it: each page was loaded and every API response verified, including that live prices are above $0.
  • Read-only: no logins, forms, carts or bookings. Pages were loaded one at a time with pauses, and robots.txt rules were respected.
  • Limits: one run from one location (US). Booking, account and payment APIs were not tested. Times include the test machine's network.
