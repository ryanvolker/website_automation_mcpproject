Account section: new user vs. existing user

Signed-in check of the My Princess account pages, November 5, 2026. Test user: a brand-new account with no cruises. Main user: an existing account with cruise history. No personal values are shown.

Short answer: both accounts work. Every page loads (HTTP 200) in about 1–3 seconds for both. The new account sees one page fewer (no cruise history yet) and no personalized deals. The same two background errors show up for both accounts, so they are site issues, not account issues.

Issues seen on both accounts

  • Warning "Recommended for You" doesn't load. The browser blocks the personalization service's reply (p13n.princess.com, ERR_BLOCKED_BY_ORB) on most account pages.
  • Warning Google Tag Manager file missing. sw_iframe.html returns 404 on nearly every page.
  • Warning JavaScript error "n.includes is not a function". This appeared for the main user only, so it may depend on account data such as past cruises.
